SetVariableNode

Modifica estado del contexto

Modifica variables...

Parametros

ParamTypeDesc
variableStringVariable name
operationEnumSET, ADD, SUB, MUL, DIV, TOGGLE
valueVariantValue to apply
scopeEnumLOCAL, SESSION, GLOBAL

Variable Scope

LOCAL Solo durante la ejecucion del grafo actual. Se pierde al terminar.
SESSION Persiste durante toda la sesion de juego. Se pierde al cerrar.
GLOBAL Persiste entre sesiones via ContextManager. Ideal para progreso permanente.

JumpToFreeNode

Escapa a conversacion libre

Concepto unico: Permite salir del grafo estructurado a una conversacion 100% libre con la IA, manteniendo el contexto del personaje. El jugador puede hablar de cualquier tema hasta que se detecte una condicion de retorno.

Parametros

ParamTypeDesc
return_keywordsArray[String]Words that trigger return
return_nodeStringNode to return to
max_turnsintMax exchanges before auto-return
↩

ReturnToGraphNode

Retorna al grafo estructurado

Complemento de JumpToFreeNode. Cuando se detecta la condicion de retorno durante el modo libre, este nodo se activa automaticamente para continuar el flujo del grafo.
