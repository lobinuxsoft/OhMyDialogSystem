CI/CD y Sistema de Releases

OhMyDialogSystem utiliza GitHub Actions para automatizar la compilacion y publicacion de releases. El sistema soporta deteccion automatica de backends en runtime, permitiendo que un solo paquete funcione en diferentes configuraciones de hardware.

Flujo de Release

1
Crear Tag

El desarrollador crea un tag de version siguiendo SemVer

git tag v1.0.0 && git push origin v1.0.0
↓
2
GitHub Actions Detecta

El workflow release-gdextension.yml se dispara automaticamente

↓
3
Compilacion Paralela

Se compila para Windows, Linux y macOS en paralelo con todos los backends

↓
4
GitHub Release

Se crea automaticamente un Release con los paquetes para cada plataforma

Backends Disponibles

El addon detecta automaticamente el mejor backend disponible en el sistema del usuario:

🖥️
CPU
Funciona en cualquier sistema. Usa instrucciones SIMD (AVX2, AVX512) si estan disponibles.
Score base: 10-170
🟢
CUDA
Para GPUs NVIDIA. Requiere driver NVIDIA instalado.
Score: 100+
🔴
Vulkan
Para GPUs AMD, Intel y NVIDIA. Requiere driver Vulkan.
Score: 80
🍎
Metal
Para Apple Silicon (M1/M2/M3). Nativo en macOS.
Score: 90

Deteccion Automatica

Cuando se carga un modelo, el sistema ejecuta el siguiente proceso:

ggml_backend_load_all()
↓
Escanea DLLs de backend
↓
ggml-cuda.dll
cudaGetDeviceCount()
ggml-vulkan.dll
vkEnumerateDevices()
ggml-cpu.dll
Siempre disponible
↓
Selecciona mayor score

Compilacion Local

Para compilar localmente con todos los backends:

Windows

cd gdextension build.bat release --all-backends --dynamic

Linux/macOS

cd gdextension ./build.sh release --all-backends --dynamic

Estructura del Workflow

El workflow de GitHub Actions (.github/workflows/release-gdextension.yml) consta de:

  • build-windows: Compila para Windows x64 con CUDA y Vulkan
  • build-linux: Compila para Linux x64 con CUDA y Vulkan
  • build-macos-arm64: Compila para Apple Silicon con Metal
  • build-macos-x64: Compila para Intel Mac (solo CPU)
  • create-release: Empaqueta y publica el Release

Actions Reutilizables

El proyecto incluye GitHub Actions personalizadas en .github/actions/:

  • setup-cuda-windows: Instala CUDA Toolkit en Windows
  • setup-cuda-linux: Instala CUDA Toolkit en Linux
  • setup-vulkan-windows: Instala Vulkan SDK en Windows
  • setup-vulkan-linux: Instala Vulkan SDK en Linux
