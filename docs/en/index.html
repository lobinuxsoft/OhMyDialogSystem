OhMyDialogSystem

Godot 4.5+ GDExtension Apache 2.0

AI-powered dialogue system for Godot that enables creating intelligent NPCs with unique personalities, persistent memories, and synthesized voices. Powered by local LLMs via llama.cpp.

✦

Main Features

🦙

Local LLM

GGUF model inference directly in Godot via llama.cpp. No external API dependencies.

🎨

Visual Editor

Integrated dialogue graph editor with AI nodes, conditions, events, and choices.

🧠

Persistent Memories

NPCs remember previous conversations with semantic search for relevant memories.

🔊

Text-to-Speech

Offline synthesized voices with Piper TTS. Each character can have their own voice.

🌐

Localization

Integration with Godot's TranslationServer. Prompts and templates in multiple languages.

🔷

C# Bindings

Idiomatic C# API with async/await, events, and complete XML documentation.

✦

Quick Start

# Create DialogueManager and verify AIService
var dialogue_manager: DialogueManager

func _ready() -> void:
    # Verify model is loaded (via Model Manager)
    var ai_service := AIService.get_singleton()
    if not ai_service or not ai_service.is_model_loaded():
        push_warning("No model loaded - use Model Manager first")

    # Create and configure DialogueManager
    dialogue_manager = DialogueManager.new()
    add_child(dialogue_manager)

    # Connect signals
    dialogue_manager.npc_response_completed.connect(_on_npc_response)
    dialogue_manager.player_choices_available.connect(_on_choices)

func start_conversation() -> void:
    var graph: DialogueGraph = preload("res://dialogues/merchant.tres")
    dialogue_manager.start_dialogue(graph)

Requirements

Component Version Notes
Godot Engine 4.5+ Required for GDExtension 4.3+
LLM Model GGUF Q4/Q5/Q8 Recommended: Qwen2.5-0.5B-Instruct (~530MB)
RAM 8GB+ 16GB recommended for larger models
GPU (optional) CUDA/Vulkan For inference acceleration
