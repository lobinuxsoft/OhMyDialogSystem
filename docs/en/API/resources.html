Resources

Resources are Godot's serializable data objects that store reusable configuration. OhMyDialogSystem uses Resources to define characters, worlds, dialogue graphs, and more.

Tip: Resources are saved as .tres files and can be created from Godot's New Resource menu, or by right-clicking in the FileSystem.

🔷 DialogueNodeData

Represents the data of an individual node in a dialogue graph. It is the basic unit of the dialogue system.

File: addons/ohmydialog/resources/dialogue_node_data.gd

Properties

Property Type Description
node_id String Unique UUID identifier for the node. Automatically generated.
node_type NodeType Node type that determines its behavior. See enum below.
editor_position Vector2 Node position in the visual GraphEdit editor.
data Dictionary Node type-specific data. Structure varies according to node_type.
output_count int Number of output slots. Automatically calculated based on type.

Enum: NodeType

Defines the 11 types of nodes available in the dialogue system:

START Graph entry point
END Terminates dialogue execution
AI_RESPONSE Generates dynamic response with LLM
STATIC_RESPONSE Displays pre-written text
PLAYER_CHOICE Presents options to the player
CONDITION Condition-based branching
EVENT Emits a signal/event to the game
SET_VARIABLE Modifies a dialogue variable
JUMP Jumps to another graph or node
JUMP_TO_FREE Escapes to free conversation mode
RETURN_TO_GRAPH Returns from free mode to graph

Methods

func validate() -> Array[String]

Validates the node data. Returns array of errors (empty if valid).

func to_dict() -> Dictionary

Serializes the node to a Dictionary for JSON storage.

static func from_dict(dict: Dictionary) -> DialogueNodeData

Creates a DialogueNodeData from a Dictionary.

static func get_type_name(type: NodeType) -> String

Returns the human-readable name of the node type.

static func get_type_color(type: NodeType) -> Color

Returns the suggested color for the node in the editor.

👤 CharacterIdentity

Defines the identity and personality of an NPC. Used to generate the system prompt that instructs the LLM how to portray the character.

File: addons/ohmydialog/resources/character_identity.gd

Properties

Group Property Type Description
Identity character_id String Unique ID for references and saves
character_name String Name displayed in dialogues
portrait Texture2D Avatar image for UI
Personality personality String Personality traits and tendencies
background String Character's history and experiences
speech_style SpeechStyle Speech style (casual, formal, medieval...)
speech_patterns String Catchphrases or verbal tics
Knowledge knowledge Array[String] Topics the character knows about
secrets Array[String] Information they hide
Motivation goals Array[String] Character's objectives
fears Array[String] Fears and aversions
Relationships relationships Dictionary character_id -> relationship description
Examples example_dialogues Array[String] Example lines demonstrating the voice

Enum: SpeechStyle

CASUALRelaxed, informal
FORMALProfessional, polite
MEDIEVALArchaic, fantasy
SCIENTIFICTechnical, precise
STREETStreet slang
POETICFlowery, metaphorical
MILITARYDirect, commanding
CHILDISHSimple, playful
ELDERLYWise, slow-paced
ROBOTICMechanical, literal

Methods

func to_system_prompt() -> String

Generates the system prompt for the LLM. This is the main method that converts character data into AI instructions.

func to_dict() -> Dictionary

Serializes the character to Dictionary.

static func from_dict(dict: Dictionary) -> CharacterIdentity

Creates a CharacterIdentity from a Dictionary.

func is_valid() -> bool

Returns true if it has character_id and character_name.

Usage Example

# Create character from code
var merchant = CharacterIdentity.new()
merchant.character_id = "merchant_grok"
merchant.character_name = "Grok el Mercader"
merchant.personality = "Amable pero astuto. Siempre busca una buena oferta."
merchant.background = "Ex-aventurero que se retiró tras perder una pierna."
merchant.speech_style = CharacterIdentity.SpeechStyle.CASUAL
merchant.knowledge = ["comercio", "armas", "rumores locales"]
merchant.goals = ["Hacer dinero", "Encontrar objetos raros"]
merchant.example_dialogues = [
    "¡Bienvenido, amigo! Tengo justo lo que necesitas.",
    "Hmm, ese precio no me convence... ¿qué tal si negociamos?"
]

# Generate system prompt for the LLM
var prompt = merchant.to_system_prompt()
print(prompt)

current_location String Current location (dynamic)
Characters important_npcs Dictionary Important NPCs in the world
Current State current_events Array[String] Current events (dynamic)
rules Array[String] World rules for the AI
dynamic_state Dictionary State variables (dynamic)
Tone & Style tone String Overall world tone
forbidden_topics Array[String] Topics to avoid

PREHISTORICBefore history

Methods

func to_context_prompt() -> String

Generates the world context to inject into LLM prompts.

func set_state(key: String, value: Variant) -> void

Updates a dynamic state variable.

func get_state(key: String, default: Variant = null) -> Variant

Gets a state variable.

func add_event(event: String) -> void

Adds a current event to the world.

func remove_event(event: String) -> void

Removes an event from the world.

Changes the current location.

Usage Example

# Create world from code
var world = WorldContext.new()
world.world_id = "darklands"
world.world_name = "Las Tierras Oscuras"
world.setting = "Un reino devastado por una guerra de 100 años."
world.time_period = WorldContext.TimePeriod.MEDIEVAL
world.lore = "Los antiguos dioses abandonaron este mundo hace siglos..."

world.factions = {
    "iron_crown": "El imperio decadente del norte",
    "free_cities": "Alianza de ciudades mercantiles del sur"
}

world.locations = {
    "ravenshollow": "Ciudad amurallada, capital del comercio",
    "blackwood": "Bosque maldito donde habitan los no-muertos"
}

world.rules = [
    "La magia es ilegal y perseguida",
    "Los nobles tienen poder absoluto",
    "No existen armas de fuego"
]

# Update state dynamically during gameplay
world.set_state("war_status", "tregua")
world.set_state("season", "invierno")
world.add_event("El rey ha enfermado gravemente")
world.set_location("ravenshollow")

# Generate context for the LLM
var context = world.to_context_prompt()

🔗 DialogueGraph

Contains a complete dialogue graph with all nodes, connections, and context. It is the main resource loaded to execute a conversation.

File: addons/ohmydialog/resources/dialogue_graph.gd

Properties

Group Property Type Description
Graph Identity graph_id String Unique graph ID
display_name String Name displayed in editor
description String Dialogue description
Context default_character CharacterIdentity Default character for AI responses
world_context WorldContext World context
Graph Data nodes Dictionary node_id -> DialogueNodeData
connections Array[Dictionary] Connections between nodes
start_node_id String Start node ID
Variables local_variables Dictionary Local dialogue variables
Editor editor_metadata Dictionary Visual editor metadata

Signals

Signal Parameters Description
node_added node: DialogueNodeData Emitted when adding a node
node_removed node_id: String Emitted when removing a node
connection_added from_node, from_slot, to_node, to_slot Emitted when creating connection
connection_removed from_node, from_slot, to_node, to_slot Emitted when removing connection

Main Methods

Node Management

func add_node(node: DialogueNodeData) -> String

Adds a node to the graph. Returns the node_id.

func create_node(type: NodeType, position: Vector2 = Vector2.ZERO) -> DialogueNodeData

Creates and adds a new node of the specified type.

func remove_node(node_id: String) -> void

Removes a node and all its connections.

func get_node(node_id: String) -> DialogueNodeData

Gets a node by its ID.

func get_start_node() -> DialogueNodeData

Gets the graph's start node.

Connection Management

func connect_nodes(from_node: String, from_slot: int, to_node: String, to_slot: int = 0) -> bool

Creates a connection between two nodes. Returns true if successful.

func disconnect_nodes(from_node: String, from_slot: int, to_node: String, to_slot: int = 0) -> void

Removes a specific connection.

func get_next_nodes(node_id: String, slot: int = 0) -> Array[DialogueNodeData]

Gets the following nodes from an output slot.

func get_next_node(node_id: String, slot: int = 0) -> DialogueNodeData

Gets the next node (for linear flow).

Validation

func validate() -> Array[String]

Validates the graph structure. Returns array of errors.

Usage Example

# Create graph programmatically
var graph = DialogueGraph.new()
graph.graph_id = "merchant_greeting"
graph.display_name = "Saludo del Mercader"
graph.default_character = preload("res://npcs/merchant.tres")
graph.world_context = preload("res://world/fantasy.tres")

# Create nodes
var start = graph.create_node(DialogueNodeData.NodeType.START)
var greeting = graph.create_node(DialogueNodeData.NodeType.AI_RESPONSE, Vector2(200, 0))
greeting.data.character_id = "merchant_grok"
greeting.data.prompt_template = "Saluda al cliente que acaba de entrar a tu tienda."

var choice = graph.create_node(DialogueNodeData.NodeType.PLAYER_CHOICE, Vector2(400, 0))
choice.data.choices = [
    {"text": "¿Qué vendes?", "condition": ""},
    {"text": "Adiós", "condition": ""}
]

var end_node = graph.create_node(DialogueNodeData.NodeType.END, Vector2(600, 100))

# Connect nodes
graph.connect_nodes(start.node_id, 0, greeting.node_id)
graph.connect_nodes(greeting.node_id, 0, choice.node_id)
graph.connect_nodes(choice.node_id, 1, end_node.node_id)  # "Adiós" -> End

# Validate
var errors = graph.validate()
if errors.is_empty():
    print("Valid graph!")
else:
    for err in errors:
        push_error(err)

# Save as resource
ResourceSaver.save(graph, "res://dialogues/merchant_greeting.tres")

⚙️ AIPreset

Stores LLM generation parameters as reusable presets. Allows quickly switching between different generation styles (creative, consistent, roleplay) without reconfiguring parameters.

File: addons/ohmydialog/resources/ai_preset.gd

Properties

Group Property Type Default Description
Identity preset_name String "Custom" Human-readable preset name
description String "" Description of when to use this preset
preset_type PresetType CUSTOM Preset type (see enum)
Temperature & Sampling temperature float 0.7 Randomness (0 = greedy, 2 = very random)
top_p float 0.9 Nucleus sampling threshold
top_k int 40 Consider only the K most probable tokens
min_p float 0.05 Minimum probability to consider token
typical_p float 1.0 Typical sampling (1.0 = disabled)
Output max_tokens int 256 Maximum tokens per response
stop_sequences Array[String] [] Sequences that stop generation
Repetition repeat_penalty float 1.1 Repetition penalty
repeat_last_n int 64 Recent tokens to consider
frequency_penalty float 0.0 Penalizes by frequency (OpenAI style)
presence_penalty float 0.0 Penalizes if appeared (OpenAI style)
Context context_size int 4096 Maximum context size in tokens
response_reserve int 256 Tokens reserved for response
Advanced seed int -1 Seed (-1 = random)
mirostat int 0 Mirostat mode (0=off, 1=v1, 2=v2)
mirostat_tau float 5.0 Mirostat target entropy
mirostat_eta float 0.1 Mirostat learning rate

Enum: PresetType

CUSTOMCustom configuration
CREATIVEHigh temperature, diverse
BALANCEDBalanced configuration
CONSISTENTLow temperature, predictable
ROLEPLAYOptimized for dialogues
TECHNICALPrecise, factual

Methods

func apply_to(llama: Object) -> void

Applies the preset parameters to a LlamaInterface instance.

func to_dict() -> Dictionary

Serializes the preset to Dictionary.

static func from_dict(dict: Dictionary) -> AIPreset

Creates an AIPreset from a Dictionary.

func get_summary() -> String

Returns preset summary for debug.

Factory Methods (Predefined Presets)

static func create_creative() -> AIPreset

Creates creative preset: temp=1.0, top_p=0.95, max_tokens=512

static func create_balanced() -> AIPreset

Creates balanced preset: temp=0.7, top_p=0.9, max_tokens=256

static func create_consistent() -> AIPreset

Creates consistent preset: temp=0.3, top_p=0.8, max_tokens=256

static func create_roleplay() -> AIPreset

Creates roleplay preset: temp=0.8, presence_penalty=0.3, max_tokens=384

static func create_technical() -> AIPreset

Creates technical preset: temp=0.2, top_p=0.7, max_tokens=512

static func get_preset(type: PresetType) -> AIPreset

Gets a preset by type.

static func create_from_gguf_metadata(metadata: Dictionary, base_type: PresetType, model_name: String) -> AIPreset

Creates preset from model's GGUF metadata, including chat template and stop sequences.

Usage Example

# Use predefined preset
var preset := AIPreset.create_roleplay()

# Apply to LlamaInterface
var llama := AIService.get_singleton().get_llama()
preset.apply_to(llama)

# Create custom preset
var custom := AIPreset.new()
custom.preset_name = "Mi Preset"
custom.temperature = 0.85
custom.top_p = 0.92
custom.max_tokens = 300
custom.stop_sequences = ["USER:", "ASSISTANT:"]

# Save as resource
ResourceSaver.save(custom, "res://presets/custom.tres")

# Load and use
var loaded := load("res://presets/custom.tres") as AIPreset
loaded.apply_to(llama)

🤖 ModelConfig

Configuration for a GGUF model. Stores model metadata, download URL, loading parameters, and default sampling settings.

File: addons/ohmydialog/resources/model_config.gd

Properties

Group Property Type Description
Model Info id String Unique model ID (e.g., "qwen2.5-0.5b")
display_name String Human-readable name
description String Model description
model_path String Path to the GGUF file
download_url String HuggingFace URL for download
documentation_url String URL to model card
size_mb float Estimated size in MB
is_custom bool Whether it's a user-added model
include_in_export bool Include in exported builds
Default Sampling default_temperature float Default temperature (0.7)
default_top_p float Default top-p (0.95)
default_top_k int Default top-k (40)
default_max_tokens int Default max tokens (256)
default_repeat_penalty float Default repeat penalty (1.1)
default_min_p float Default min-p (0.05)
Context n_ctx int Context size in tokens (2048)
n_gpu_layers int GPU layers (-1 = all, 0 = CPU)
n_batch int Batch size for prompt (512)
GGUF Metadata architecture String Architecture (llama, qwen2, phi...)
raw_chat_template String Model's Jinja2 chat template
chat_template_format String Detected format (chatml, llama3...)
bos_token_id int BOS token ID (-1 if none)
eos_token_id int EOS token ID (-1 if none)
ai_preset AIPreset Associated preset generated from metadata

Methods

func get_load_params() -> Dictionary

Returns parameters for LlamaInterface.load_model() (n_ctx, n_gpu_layers, n_batch).

func apply_defaults_to(llama: LlamaInterface) -> void

Applies default sampling parameters to the instance.

func is_downloaded() -> bool

Returns true if the model exists in the filesystem.

func get_filename() -> String

Extracts the filename from the URL or generates one based on the ID.

func get_effective_path() -> String

Returns the effective path where to look for the model (res://models/).

func is_valid() -> bool

Returns true if it has id and display_name.

func get_summary() -> String

Returns summary for debug.

func populate_from_metadata(metadata: Dictionary) -> void

Fills GGUF metadata fields from a Dictionary.

func create_ai_preset() -> AIPreset

Creates an AIPreset based on model metadata.

func has_metadata() -> bool

Returns true if it has populated GGUF metadata.

Usage Example

# Create model configuration
var config := ModelConfig.new()
config.id = "smollm2-360m"
config.display_name = "SmolLM2 360M Instruct"
config.download_url = "https://huggingface.co/HuggingFaceTB/SmolLM2-360M-Instruct-GGUF/resolve/main/smollm2-360m-instruct-q4_k_m.gguf"
config.size_mb = 254.0
config.n_ctx = 2048
config.n_gpu_layers = -1  # All on GPU

# Check if downloaded
if config.is_downloaded():
    print("Model available at: ", config.get_effective_path())

# Load model via AIService
var ai_service := AIService.get_singleton()
var err := ai_service.load_model(config)
if err == OK:
    print("Model loaded!")

# Defaults are applied automatically, but you can do it manually:
config.apply_defaults_to(ai_service.get_llama())
