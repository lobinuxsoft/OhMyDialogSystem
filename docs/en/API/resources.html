Resources

Los Resources son objetos de datos serializables de Godot que almacenan configuración reutilizable. OhMyDialogSystem usa Resources para definir personajes, mundos, grafos de diálogo y más.

Tip: Los Resources se guardan como archivos .tres y se pueden crear desde el menú New Resource en Godot, o desde el FileSystem haciendo click derecho.

🔷 DialogueNodeData

Representa los datos de un nodo individual en un grafo de diálogo. Es la unidad básica del sistema de diálogos.

Archivo: addons/ohmydialog/resources/dialogue_node_data.gd

Propiedades

Propiedad Tipo Descripción
node_id String Identificador único UUID del nodo. Se genera automáticamente.
node_type NodeType Tipo de nodo que determina su comportamiento. Ver enum abajo.
editor_position Vector2 Posición del nodo en el editor visual GraphEdit.
data Dictionary Datos específicos del tipo de nodo. La estructura varía según node_type.
output_count int Número de slots de salida. Calculado automáticamente según el tipo.

Enum: NodeType

Define los 11 tipos de nodos disponibles en el sistema de diálogos:

START Punto de entrada del grafo
END Termina la ejecución del diálogo
AI_RESPONSE Genera respuesta dinámica con LLM
STATIC_RESPONSE Muestra texto pre-escrito
PLAYER_CHOICE Presenta opciones al jugador
CONDITION Bifurcación basada en condición
EVENT Emite un signal/evento al juego
SET_VARIABLE Modifica una variable de diálogo
JUMP Salta a otro grafo o nodo
JUMP_TO_FREE Escapa a modo conversación libre
RETURN_TO_GRAPH Retorna del modo libre al grafo

Métodos

func validate() -> Array[String]

Valida los datos del nodo. Retorna array de errores (vacío si es válido).

func to_dict() -> Dictionary

Serializa el nodo a un Dictionary para almacenamiento JSON.

static func from_dict(dict: Dictionary) -> DialogueNodeData

Crea un DialogueNodeData desde un Dictionary.

static func get_type_name(type: NodeType) -> String

Retorna el nombre legible del tipo de nodo.

static func get_type_color(type: NodeType) -> Color

Retorna el color sugerido para el nodo en el editor.

👤 CharacterIdentity

Define la identidad y personalidad de un NPC. Se usa para generar el system prompt que instruye al LLM cómo interpretar al personaje.

Archivo: addons/ohmydialog/resources/character_identity.gd

Propiedades

Grupo Propiedad Tipo Descripción
Identity character_id String ID único para referencias y guardados
character_name String Nombre mostrado en diálogos
portrait Texture2D Imagen de avatar para UI
Personality personality String Rasgos de personalidad y tendencias
background String Historia y experiencias del personaje
speech_style SpeechStyle Estilo de habla (casual, formal, medieval...)
speech_patterns String Muletillas o tics verbales
Knowledge knowledge Array[String] Temas que el personaje conoce
secrets Array[String] Información que oculta
Motivation goals Array[String] Objetivos del personaje
fears Array[String] Miedos y aversiones
Relationships relationships Dictionary character_id → descripción de relación
Examples example_dialogues Array[String] Líneas de ejemplo que demuestran la voz

Enum: SpeechStyle

CASUALRelajado, informal
FORMALProfesional, cortés
MEDIEVALArcaico, fantasía
SCIENTIFICTécnico, preciso
STREETJerga callejera
POETICFlorido, metafórico
MILITARYDirecto, comandante
CHILDISHSimple, juguetón
ELDERLYSabio, pausado
ROBOTICMecánico, literal

Métodos

func to_system_prompt() -> String

Genera el system prompt para el LLM. Este es el método principal que convierte los datos del personaje en instrucciones para la IA.

func to_dict() -> Dictionary

Serializa el personaje a Dictionary.

static func from_dict(dict: Dictionary) -> CharacterIdentity

Crea un CharacterIdentity desde un Dictionary.

func is_valid() -> bool

Retorna true si tiene character_id y character_name.

Ejemplo de Uso

# Crear personaje desde código
var merchant = CharacterIdentity.new()
merchant.character_id = "merchant_grok"
merchant.character_name = "Grok el Mercader"
merchant.personality = "Amable pero astuto. Siempre busca una buena oferta."
merchant.background = "Ex-aventurero que se retiró tras perder una pierna."
merchant.speech_style = CharacterIdentity.SpeechStyle.CASUAL
merchant.knowledge = ["comercio", "armas", "rumores locales"]
merchant.goals = ["Hacer dinero", "Encontrar objetos raros"]
merchant.example_dialogues = [
    "¡Bienvenido, amigo! Tengo justo lo que necesitas.",
    "Hmm, ese precio no me convence... ¿qué tal si negociamos?"
]

# Generar system prompt para el LLM
var prompt = merchant.to_system_prompt()
print(prompt)

🌍 WorldContext

Define el contexto del mundo para la generación de diálogos. Incluye setting, lore, eventos actuales y estado dinámico que puede cambiar durante el juego.

Archivo: addons/ohmydialog/resources/world_context.gd

Propiedades

Grupo Propiedad Tipo Descripción
World Identity world_id String ID único del contexto
world_name String Nombre del mundo/setting
setting String Descripción breve del escenario
time_period TimePeriod Era tecnológica y cultural
Lore & History lore String Historia profunda del mundo
factions Dictionary faction_id → descripción
Geography locations Dictionary location_id → descripción
current_location String Ubicación actual (dinámico)
Characters important_npcs Dictionary NPCs importantes del mundo
Current State current_events Array[String] Eventos actuales (dinámico)
rules Array[String] Reglas del mundo para la IA
dynamic_state Dictionary Variables de estado (dinámico)
Tone & Style tone String Tono general del mundo
forbidden_topics Array[String] Temas a evitar

Enum: TimePeriod

PREHISTORICAntes de la historia
ANCIENTCivilizaciones antiguas
MEDIEVALEdad media
RENAISSANCERenacimiento
INDUSTRIALEra industrial
MODERNMundo contemporáneo
NEAR_FUTUREFuturo cercano
FAR_FUTUREFuturo lejano
POST_APOCALYPTICPost-apocalíptico
FANTASYFantasía con magia
STEAMPUNKVictoriano + vapor
CYBERPUNKAlta tech, distopía

Métodos

func to_context_prompt() -> String

Genera el contexto del mundo para inyectar en prompts del LLM.

func set_state(key: String, value: Variant) -> void

Actualiza una variable de estado dinámico.

func get_state(key: String, default: Variant = null) -> Variant

Obtiene una variable de estado.

func add_event(event: String) -> void

Agrega un evento actual al mundo.

func remove_event(event: String) -> void

Elimina un evento del mundo.

func set_location(location_id: String) -> void

Cambia la ubicación actual.

Ejemplo de Uso

# Crear mundo desde código
var world = WorldContext.new()
world.world_id = "darklands"
world.world_name = "Las Tierras Oscuras"
world.setting = "Un reino devastado por una guerra de 100 años."
world.time_period = WorldContext.TimePeriod.MEDIEVAL
world.lore = "Los antiguos dioses abandonaron este mundo hace siglos..."

world.factions = {
    "iron_crown": "El imperio decadente del norte",
    "free_cities": "Alianza de ciudades mercantiles del sur"
}

world.locations = {
    "ravenshollow": "Ciudad amurallada, capital del comercio",
    "blackwood": "Bosque maldito donde habitan los no-muertos"
}

world.rules = [
    "La magia es ilegal y perseguida",
    "Los nobles tienen poder absoluto",
    "No existen armas de fuego"
]

# Actualizar estado dinámicamente durante el juego
world.set_state("war_status", "tregua")
world.set_state("season", "invierno")
world.add_event("El rey ha enfermado gravemente")
world.set_location("ravenshollow")

# Generar contexto para el LLM
var context = world.to_context_prompt()

🔗 DialogueGraph

Contiene un grafo completo de diálogo con todos los nodos, conexiones y contexto. Es el recurso principal que se carga para ejecutar una conversación.

Archivo: addons/ohmydialog/resources/dialogue_graph.gd

Propiedades

Grupo Propiedad Tipo Descripción
Graph Identity graph_id String ID único del grafo
display_name String Nombre mostrado en el editor
description String Descripción del diálogo
Context default_character CharacterIdentity Personaje por defecto para respuestas IA
world_context WorldContext Contexto del mundo
Graph Data nodes Dictionary node_id → DialogueNodeData
connections Array[Dictionary] Conexiones entre nodos
start_node_id String ID del nodo de inicio
Variables local_variables Dictionary Variables locales del diálogo
Editor editor_metadata Dictionary Metadatos del editor visual

Signals

Signal Parámetros Descripción
node_added node: DialogueNodeData Emitido al agregar un nodo
node_removed node_id: String Emitido al eliminar un nodo
connection_added from_node, from_slot, to_node, to_slot Emitido al crear conexión
connection_removed from_node, from_slot, to_node, to_slot Emitido al eliminar conexión

Métodos Principales

Gestión de Nodos

func add_node(node: DialogueNodeData) -> String

Agrega un nodo al grafo. Retorna el node_id.

func create_node(type: NodeType, position: Vector2 = Vector2.ZERO) -> DialogueNodeData

Crea y agrega un nuevo nodo del tipo especificado.

func remove_node(node_id: String) -> void

Elimina un nodo y todas sus conexiones.

func get_node(node_id: String) -> DialogueNodeData

Obtiene un nodo por su ID.

func get_start_node() -> DialogueNodeData

Obtiene el nodo de inicio del grafo.

Gestión de Conexiones

func connect_nodes(from_node: String, from_slot: int, to_node: String, to_slot: int = 0) -> bool

Crea una conexión entre dos nodos. Retorna true si tuvo éxito.

func disconnect_nodes(from_node: String, from_slot: int, to_node: String, to_slot: int = 0) -> void

Elimina una conexión específica.

func get_next_nodes(node_id: String, slot: int = 0) -> Array[DialogueNodeData]

Obtiene los nodos siguientes desde un slot de salida.

func get_next_node(node_id: String, slot: int = 0) -> DialogueNodeData

Obtiene el siguiente nodo (para flujo lineal).

Validación

func validate() -> Array[String]

Valida la estructura del grafo. Retorna array de errores.

Ejemplo de Uso

# Crear grafo programáticamente
var graph = DialogueGraph.new()
graph.graph_id = "merchant_greeting"
graph.display_name = "Saludo del Mercader"
graph.default_character = preload("res://npcs/merchant.tres")
graph.world_context = preload("res://world/fantasy.tres")

# Crear nodos
var start = graph.create_node(DialogueNodeData.NodeType.START)
var greeting = graph.create_node(DialogueNodeData.NodeType.AI_RESPONSE, Vector2(200, 0))
greeting.data.character_id = "merchant_grok"
greeting.data.prompt_template = "Saluda al cliente que acaba de entrar a tu tienda."

var choice = graph.create_node(DialogueNodeData.NodeType.PLAYER_CHOICE, Vector2(400, 0))
choice.data.choices = [
    {"text": "¿Qué vendes?", "condition": ""},
    {"text": "Adiós", "condition": ""}
]

var end_node = graph.create_node(DialogueNodeData.NodeType.END, Vector2(600, 100))

# Conectar nodos
graph.connect_nodes(start.node_id, 0, greeting.node_id)
graph.connect_nodes(greeting.node_id, 0, choice.node_id)
graph.connect_nodes(choice.node_id, 1, end_node.node_id)  # "Adiós" -> End

# Validar
var errors = graph.validate()
if errors.is_empty():
    print("Grafo válido!")
else:
    for err in errors:
        push_error(err)

# Guardar como resource
ResourceSaver.save(graph, "res://dialogues/merchant_greeting.tres")

⚙️ AIPreset

Almacena parámetros de generación LLM como presets reutilizables. Permite cambiar rápidamente entre diferentes estilos de generación (creativo, consistente, roleplay) sin reconfigurar parámetros.

Archivo: addons/ohmydialog/resources/ai_preset.gd

Propiedades

Grupo Propiedad Tipo Default Descripción
Identity preset_name String "Custom" Nombre legible del preset
description String "" Descripción de cuándo usar este preset
preset_type PresetType CUSTOM Tipo de preset (ver enum)
Temperature & Sampling temperature float 0.7 Aleatoriedad (0 = greedy, 2 = muy aleatorio)
top_p float 0.9 Nucleus sampling threshold
top_k int 40 Considerar solo los K tokens más probables
min_p float 0.05 Probabilidad mínima para considerar token
typical_p float 1.0 Typical sampling (1.0 = deshabilitado)
Output max_tokens int 256 Máximo de tokens por respuesta
stop_sequences Array[String] [] Secuencias que detienen la generación
Repetition repeat_penalty float 1.1 Penalización por repetición
repeat_last_n int 64 Tokens recientes a considerar
frequency_penalty float 0.0 Penaliza por frecuencia (estilo OpenAI)
presence_penalty float 0.0 Penaliza si apareció (estilo OpenAI)
Context context_size int 4096 Tamaño máximo de contexto en tokens
response_reserve int 256 Tokens reservados para respuesta
Advanced seed int -1 Semilla (-1 = aleatorio)
mirostat int 0 Modo Mirostat (0=off, 1=v1, 2=v2)
mirostat_tau float 5.0 Entropía objetivo Mirostat
mirostat_eta float 0.1 Tasa de aprendizaje Mirostat

Enum: PresetType

CUSTOMConfiguración personalizada
CREATIVEAlta temperatura, diverso
BALANCEDConfiguración balanceada
CONSISTENTBaja temperatura, predecible
ROLEPLAYOptimizado para diálogos
TECHNICALPreciso, factual

Métodos

func apply_to(llama: Object) -> void

Aplica los parámetros del preset a una instancia de LlamaInterface.

func to_dict() -> Dictionary

Serializa el preset a Dictionary.

static func from_dict(dict: Dictionary) -> AIPreset

Crea un AIPreset desde un Dictionary.

func get_summary() -> String

Retorna resumen del preset para debug.

Factory Methods (Presets Predefinidos)

static func create_creative() -> AIPreset

Crea preset creativo: temp=1.0, top_p=0.95, max_tokens=512

static func create_balanced() -> AIPreset

Crea preset balanceado: temp=0.7, top_p=0.9, max_tokens=256

static func create_consistent() -> AIPreset

Crea preset consistente: temp=0.3, top_p=0.8, max_tokens=256

static func create_roleplay() -> AIPreset

Crea preset roleplay: temp=0.8, presence_penalty=0.3, max_tokens=384

static func create_technical() -> AIPreset

Crea preset técnico: temp=0.2, top_p=0.7, max_tokens=512

static func get_preset(type: PresetType) -> AIPreset

Obtiene un preset por tipo.

static func create_from_gguf_metadata(metadata: Dictionary, base_type: PresetType, model_name: String) -> AIPreset

Crea preset desde metadatos GGUF del modelo, incluyendo chat template y stop sequences.

Ejemplo de Uso

# Usar preset predefinido
var preset := AIPreset.create_roleplay()

# Aplicar a LlamaInterface
var llama := AIService.get_singleton().get_llama()
preset.apply_to(llama)

# Crear preset personalizado
var custom := AIPreset.new()
custom.preset_name = "Mi Preset"
custom.temperature = 0.85
custom.top_p = 0.92
custom.max_tokens = 300
custom.stop_sequences = ["USER:", "ASSISTANT:"]

# Guardar como resource
ResourceSaver.save(custom, "res://presets/custom.tres")

# Cargar y usar
var loaded := load("res://presets/custom.tres") as AIPreset
loaded.apply_to(llama)

🤖 ModelConfig

Configuración para un modelo GGUF. Almacena metadatos del modelo, URL de descarga, parámetros de carga y sampling por defecto.

Archivo: addons/ohmydialog/resources/model_config.gd

Propiedades

Grupo Propiedad Tipo Descripción
Model Info id String ID único del modelo (e.g., "qwen2.5-0.5b")
display_name String Nombre legible
description String Descripción del modelo
model_path String Ruta al archivo GGUF
download_url String URL de HuggingFace para descarga
documentation_url String URL a la model card
size_mb float Tamaño estimado en MB
is_custom bool Si es modelo agregado por usuario
include_in_export bool Incluir en builds exportados
Default Sampling default_temperature float Temperatura por defecto (0.7)
default_top_p float Top-p por defecto (0.95)
default_top_k int Top-k por defecto (40)
default_max_tokens int Max tokens por defecto (256)
default_repeat_penalty float Repeat penalty por defecto (1.1)
default_min_p float Min-p por defecto (0.05)
Context n_ctx int Tamaño de contexto en tokens (2048)
n_gpu_layers int Capas GPU (-1 = todas, 0 = CPU)
n_batch int Batch size para prompt (512)
GGUF Metadata architecture String Arquitectura (llama, qwen2, phi...)
raw_chat_template String Chat template Jinja2 del modelo
chat_template_format String Formato detectado (chatml, llama3...)
bos_token_id int ID del token BOS (-1 si no existe)
eos_token_id int ID del token EOS (-1 si no existe)
ai_preset AIPreset Preset asociado generado de metadatos

Métodos

func get_load_params() -> Dictionary

Retorna parámetros para LlamaInterface.load_model() (n_ctx, n_gpu_layers, n_batch).

func apply_defaults_to(llama: LlamaInterface) -> void

Aplica parámetros de sampling por defecto a la instancia.

func is_downloaded() -> bool

Retorna true si el modelo existe en el sistema de archivos.

func get_filename() -> String

Extrae el nombre del archivo de la URL o genera uno basado en el ID.

func get_effective_path() -> String

Retorna la ruta efectiva donde buscar el modelo (res://models/).

func is_valid() -> bool

Retorna true si tiene id y display_name.

func get_summary() -> String

Retorna resumen para debug.

func populate_from_metadata(metadata: Dictionary) -> void

Llena campos de metadatos GGUF desde un Dictionary.

func create_ai_preset() -> AIPreset

Crea un AIPreset basado en los metadatos del modelo.

func has_metadata() -> bool

Retorna true si tiene metadatos GGUF poblados.

Ejemplo de Uso

# Crear configuración de modelo
var config := ModelConfig.new()
config.id = "smollm2-360m"
config.display_name = "SmolLM2 360M Instruct"
config.download_url = "https://huggingface.co/HuggingFaceTB/SmolLM2-360M-Instruct-GGUF/resolve/main/smollm2-360m-instruct-q4_k_m.gguf"
config.size_mb = 254.0
config.n_ctx = 2048
config.n_gpu_layers = -1  # Todas en GPU

# Verificar si está descargado
if config.is_downloaded():
    print("Modelo disponible en: ", config.get_effective_path())

# Cargar modelo via AIService
var ai_service := AIService.get_singleton()
var err := ai_service.load_model(config)
if err == OK:
    print("Modelo cargado!")

# Los defaults se aplican automáticamente, pero puedes hacerlo manualmente:
config.apply_defaults_to(ai_service.get_llama())
