Wiki / API Reference / LlamaInterface

🦙 LlamaInterface

GDExtension C++

Low-level interface for llama.cpp. Allows loading GGUF models and managing their lifecycle.

Note: This class is part of the native GDExtension module. It requires the addon to be correctly compiled for your platform.

Inheritance

RefCounted → LlamaInterface

Description

LlamaInterface provides a low-level API for loading language models in GGUF format using the llama.cpp library. This class handles backend initialization, model loading, memory management, and inference context.

It is the foundation upon which higher-level components like AIService and DialogueManager are built.

Recommended Usage: For most use cases, use AIService instead of instantiating LlamaInterface directly:

# Recommended way - use AIService singleton
var ai_service := AIService.get_singleton()
if ai_service and ai_service.is_model_loaded():
    # The model is already available globally
    pass

# Direct way (low level) - instantiate LlamaInterface
var llama := LlamaInterface.new()
llama.load_model("res://models/model.gguf")

AIService manages the model lifecycle, integrates with ModelManager for model downloads, and provides signals for state changes.

Method Descriptions

load_model

Error load_model(path: String, params: Dictionary = {})

Loads a GGUF model from the specified path.

Parameters

Parameter Type Description
path String Path to the .gguf file. Supports res:// and user://
params Dictionary Optional configuration parameters

Dictionary Parameters

Key Type Default Description
n_ctx int model Context size in tokens
n_gpu_layers int 0 Layers to offload to GPU (0 = CPU only)
n_batch int 512 Batch size for processing
n_threads int auto Threads for generation
n_threads_batch int auto Threads for batch processing
use_mmap bool true Use memory-mapped file
use_mlock bool false Lock model in RAM
vocab_only bool false Only load vocabulary (without weights)

Return

Returns OK if the model loaded correctly, or an error code:

  • ERR_FILE_NOT_FOUND - File does not exist
  • ERR_CANT_OPEN - Could not open/parse the model
  • ERR_CANT_CREATE - Could not create the context

Example

var llama = LlamaInterface.new()
var err = llama.load_model("user://models/mistral-7b-q4.gguf", {
    "n_ctx": 4096,
    "n_gpu_layers": 0
})

if err != OK:
    push_error("Failed to load model: " + str(err))
    return

print("Model loaded successfully!")

unload_model

void unload_model()

Unloads the current model and frees all associated resources (context, backend, memory).

It is safe to call this method even if no model is loaded.

Example

llama.unload_model()
print("Model unloaded")

is_model_loaded

bool is_model_loaded() const

Checks if a model is loaded and ready to use.

Return

true if a model is loaded, false otherwise.

Example

if llama.is_model_loaded():
    print("Ready to generate!")
else:
    print("No model loaded")

get_model_info

Dictionary get_model_info() const

Returns detailed information about the loaded model.

Return

A Dictionary with the following keys (empty if no model is loaded):

Key Type Description
description String Model description
path String Path of the loaded file
size_bytes int Model size in bytes
n_params int Number of parameters
n_ctx_train int Training context
n_embd int Embedding dimension
n_layer int Number of layers
n_head int Number of attention heads
n_ctx int Current configured context
n_batch int Current batch size
vocab_size int Vocabulary size
vocab_type int Tokenizer type (0=SPM, 1=BPE, etc.)
bos_token int BOS token ID
eos_token int EOS token ID
has_encoder bool Whether the model has an encoder
has_decoder bool Whether the model has a decoder
is_recurrent bool Whether it's recurrent (Mamba, RWKV)
rope_type int RoPE type

GPU/Backend Information

Key Type Description
n_gpu_layers int Actual number of layers on GPU (0 = CPU only)
gpu_backend_name String Backend name: "Vulkan0", "CUDA0", "Metal", "CPU"
gpu_backend_desc String Device description (e.g., "AMD Radeon RX 9070 XT")

Example

var info = llama.get_model_info()
if not info.is_empty():
    print("Model: ", info.description)
    print("Parameters: ", info.n_params / 1_000_000_000.0, "B")
    print("Context: ", info.n_ctx, " tokens")
    print("Layers: ", info.n_layer)

    # GPU info
    var gpu_layers = info.get("n_gpu_layers", 0)
    var backend = info.get("gpu_backend_name", "CPU")
    if gpu_layers > 0:
        print("GPU: ", info.get("gpu_backend_desc", ""))
        print("Layers on GPU: %d/%d" % [gpu_layers, info.n_layer])
    else:
        print("Running on CPU only")

get_system_info

String get_system_info() const

Returns system information: CPU features and available backends.

Return

String in format "FEATURE = 0/1 | FEATURE = 0/1 | ..." including:

  • CPU: AVX, AVX2, AVX512, FMA, F16C, NEON
  • GPU: VULKAN, CUDA, METAL

Example

var sys_info = llama.get_system_info()
print(sys_info)
# Output: "AVX = 1 | AVX2 = 1 | AVX512 = 0 | ... | VULKAN = 1 | CUDA = 0"

# Parse specific features

    print("AVX2 supported!")
if "VULKAN = 1" in sys_info:
    print("Vulkan backend available!")

get_chat_template

String get_chat_template() const

Gets the chat template embedded in the model's metadata (Jinja2 format).

Return

The chat template, or an empty String if the model doesn't include one.

Note: Most modern chat models (Llama 3, Qwen, Mistral) include their template. Base models usually don't have one.

apply_chat_template

String apply_chat_template(messages: Array, add_generation_prompt: bool = true) const

Formats conversation messages using the model's template. Uses llama.cpp's native parser (minja).

Parameters

Parameter Type Description
messages Array Array of dictionaries with role and content
add_generation_prompt bool If true, adds the prefix for the model to respond

Example

var messages = [
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "Hello!"},
    {"role": "assistant", "content": "Hi! How can I help?"},
    {"role": "user", "content": "Tell me a joke."}
]

var prompt = llama.apply_chat_template(messages, true)
var response = llama.generate(prompt)

count_tokens

int count_tokens(text: String) const

Counts tokens using the loaded model's exact tokenizer.

Return

Number of tokens, or -1 if no model is loaded.

Example

var text = "Hello, world! This is a test."
var token_count = llama.count_tokens(text)
print("Tokens: ", token_count)  # Varies by model, typically ~8-10

# Verify that the prompt fits in the context
var model_info = llama.get_model_info()
var max_ctx = model_info.get("n_ctx", 4096)
if token_count > max_ctx - 512:  # Reserve space for response
    print("Warning: Prompt may be too long!")

Text Generation

generate

String generate(prompt: String)

Generates text synchronously (blocking) from a prompt.

Parameters

Parameter Type Description
prompt String The input text to continue

Return

The generated text, or an empty String if there's an error or no model is loaded.

Example

var llama = LlamaInterface.new()
llama.load_model("res://models/mistral-7b-q4.gguf")

# Configure parameters
llama.set_temperature(0.7)
llama.set_max_tokens(100)

# Generate text
var response = llama.generate("The quick brown fox")
print(response)  # " jumps over the lazy dog..."
Note: This operation is blocking. For non-blocking generation, use generate_async() or generate_streaming().

generate_async

void generate_async(prompt: String)

Generates text asynchronously in a worker thread. Does not block the main thread.

Emitted Signals

  • generation_started - When starting
  • generation_completed(text) - When finished successfully
  • generation_error(message) - If there's an error
  • generation_cancelled - If cancelled

Example

func _ready():
    llama.generation_completed.connect(_on_completed)
    llama.generation_error.connect(_on_error)

func generate_response():
    llama.generate_async("What is the meaning of life?")
    # Returns immediately, result via signal

func _on_completed(text: String):
    print("Response: ", text)

func _on_error(message: String):
    push_error("Failed: " + message)

generate_streaming

void generate_streaming(prompt: String)

Generates text with streaming: emits each token as it's generated. Ideal for progressively displaying responses in the UI.

Emitted Signals

  • generation_started - When starting
  • token_generated(token) - For each token generated
  • generation_progress(tokens, max_tokens) - Periodic progress
  • generation_completed(text) - When finished (complete text)

Example

@onready var label: RichTextLabel = %ResponseLabel

func _ready():
    llama.generation_started.connect(func(): label.text = "")
    llama.token_generated.connect(func(token): label.text += token)
    llama.generation_completed.connect(_on_done)

func start_chat():
    llama.generate_streaming("Tell me about space exploration")

func _on_done(full_text: String):
    print("Generation finished, %d characters" % full_text.length())

is_generating

bool is_generating() const

Checks if an async or streaming generation is in progress.

Example

func _on_send_pressed():
    if llama.is_generating():
        print("Already generating, please wait...")
        return
    llama.generate_streaming(input.text)

get_generation_progress

float get_generation_progress() const

Returns the current generation progress as a value between 0.0 and 1.0.

Return

tokens_generated / max_tokens. Returns 0.0 if no generation is in progress.

Example

func _process(_delta):
    if llama.is_generating():
        progress_bar.value = llama.get_generation_progress() * 100.0

cancel_generation

void cancel_generation()

Cancels an async or streaming generation in progress. Emits generation_cancelled when the generation stops.

Example

func _on_cancel_pressed():
    if llama.is_generating():
        llama.cancel_generation()
        status_label.text = "Cancelled"

Sampling Parameters

set_temperature / get_temperature

void set_temperature(temperature: float)
float get_temperature() const

Controls the randomness of generation.

  • 0.0 = Greedy (always chooses the most probable token)
  • 0.7-0.9 = Balance between creativity/coherence (recommended)
  • 1.0+ = More random/creative

Default: 0.8

set_top_p / get_top_p

void set_top_p(top_p: float)
float get_top_p() const

Nucleus sampling - considers only tokens whose cumulative probability is ≤ top_p.

Default: 0.95 | Range: 0.0 - 1.0

set_top_k / get_top_k

void set_top_k(top_k: int)
int get_top_k() const

Considers only the top-k most probable tokens. 0 = disabled.

Default: 40

set_max_tokens / get_max_tokens

void set_max_tokens(max_tokens: int)
int get_max_tokens() const

Maximum number of tokens to generate. Minimum: 1.

Default: 256

set_repeat_penalty / get_repeat_penalty

void set_repeat_penalty(penalty: float)
float get_repeat_penalty() const

Penalizes token repetition. 1.0 = no penalty.

Default: 1.1 | Range: 1.0 - 2.0

set_frequency_penalty / get_frequency_penalty

void set_frequency_penalty(penalty: float)
float get_frequency_penalty() const

Penalizes tokens based on their frequency in the generated text. Reduces repetition of common words.

  • 0.0 = No penalty
  • 0.5-1.0 = Moderate penalty
  • 2.0 = Strong penalty

Default: 0.0 | Range: 0.0 - 2.0

set_presence_penalty / get_presence_penalty

void set_presence_penalty(penalty: float)
float get_presence_penalty() const

Penalizes tokens that have already appeared (regardless of frequency). Encourages new topics.

  • 0.0 = No penalty
  • 0.5-1.0 = Encourages variety
  • 2.0 = Strongly avoids repeating concepts

Default: 0.0 | Range: 0.0 - 2.0

set_repeat_last_n / get_repeat_last_n

void set_repeat_last_n(n: int)
int get_repeat_last_n() const

Defines how many tokens to look back when applying repeat_penalty.

  • 0 = Disabled (no repetition context)
  • 64 = Last 64 tokens (recommended)
  • -1 = Entire context (can be slow)

Default: 64

set_min_p / get_min_p

void set_min_p(min_p: float)
float get_min_p() const

Filters tokens with probability less than min_p * prob_max.

Default: 0.05 | Range: 0.0 - 1.0

set_seed / get_seed

void set_seed(seed: int)
int get_seed() const

Seed for reproducibility. 0xFFFFFFFF = random.

Default: 0xFFFFFFFF (random)

Timeout

set_timeout / get_timeout

void set_timeout(timeout_ms: int)
int get_timeout() const

Configures the maximum timeout for generation in milliseconds.

  • 0 = No timeout (waits indefinitely)
  • >0 = Maximum time in ms

Default: 0 (no timeout)

Example

    print("Generation timed out!")
    print("Partial response: ", response)

Signals

Async Generation

Signal Description
generation_started() Emitted when an async or streaming generation begins
generation_completed(text: String) Emitted when generation finishes successfully. text contains the complete result.
generation_error(message: String) Emitted when an error occurs during generation
generation_cancelled() Emitted when generation is cancelled via cancel_generation()

Streaming

Signal Description

generation_progress(tokens: int, max_tokens: int) Emitted periodically with generation progress. Useful for progress bars.

Streaming Example

func _ready():
    llama = LlamaInterface.new()
    llama.generation_started.connect(_on_started)
    llama.token_generated.connect(_on_token)
    llama.generation_completed.connect(_on_completed)
    llama.generation_error.connect(_on_error)
    llama.generation_cancelled.connect(_on_cancelled)

func start_streaming():
    llama.generate_streaming("Tell me a story about")

func _on_started():
    label.text = ""
    print("Generation started...")

func _on_token(token: String):
    label.text += token  # Append each token as it arrives

func _on_completed(full_text: String):
    print("Done! Total length: ", full_text.length())

func _on_error(message: String):
    push_error("Generation failed: " + message)

func _on_cancelled():
    print("Generation was cancelled")

Complete Example

extends Node
## Complete example showing sync and async generation with GPU support

var llama: LlamaInterface
@onready var output_label: RichTextLabel = %OutputLabel
@onready var progress_bar: ProgressBar = %ProgressBar

func _ready():
    llama = LlamaInterface.new()

    # Connect async signals
    llama.generation_started.connect(_on_generation_started)
    llama.token_generated.connect(_on_token_generated)
    llama.generation_completed.connect(_on_generation_completed)
    llama.generation_error.connect(_on_generation_error)
    llama.generation_timeout.connect(_on_generation_timeout)

    # Load model with GPU offloading
    var err = llama.load_model("user://models/qwen2.5-7b-q4_k_m.gguf", {
        "n_ctx": 8192,
        "n_gpu_layers": -1,  # -1 = all layers to GPU
        "n_threads": 8
    })

    if err != OK:
        push_error("Error loading model")
        return

    _print_model_info()
    _configure_generation()


func _print_model_info():
    var info = llama.get_model_info()
    print("=== Model Info ===")
    print("Description: ", info.get("description", "Unknown"))
    print("Parameters: %.1fB" % (info.get("n_params", 0) / 1_000_000_000.0))
    print("Context: %d tokens" % info.get("n_ctx", 0))

    # GPU info
    var gpu_layers = info.get("n_gpu_layers", 0)
    var backend = info.get("gpu_backend_name", "CPU")
    if gpu_layers > 0:
        print("GPU: %s (%s)" % [backend, info.get("gpu_backend_desc", "")])
        print("Layers on GPU: %d/%d" % [gpu_layers, info.get("n_layer", 0)])
    else:
        print("Running on CPU")

    # System capabilities
    var sys_info = llama.get_system_info()
    if "VULKAN = 1" in sys_info:
        print("Vulkan: Available")
    if "AVX2 = 1" in sys_info:
        print("AVX2: Available")


func _configure_generation():
    llama.set_temperature(0.7)
    llama.set_top_p(0.9)
    llama.set_max_tokens(256)
    llama.set_repeat_penalty(1.1)
    llama.set_frequency_penalty(0.5)
    llama.set_timeout(60000)  # 60 second timeout
    llama.set_stop_sequences(["User:", "\n\n", "<|im_end|>"])


func generate_with_chat_template():
    # Use model's built-in chat template
    var messages = [
        {"role": "system", "content": "You are a helpful NPC in a fantasy game."},
        {"role": "user", "content": "What quests do you have for me?"}
    ]

    var prompt = llama.apply_chat_template(messages, true)
    var tokens = llama.count_tokens(prompt)
    print("Prompt tokens: ", tokens)

    # Start streaming generation
    llama.generate_streaming(prompt)


func _on_generation_started():
    output_label.text = ""
    progress_bar.value = 0
    print("Generation started...")


func _on_token_generated(token: String):
    output_label.text += token


func _process(_delta):
    if llama.is_generating():
        progress_bar.value = llama.get_generation_progress() * 100.0


func _on_generation_completed(full_text: String):
    print("Done! Generated %d characters" % full_text.length())
    progress_bar.value = 100


func _on_generation_error(message: String):
    push_error("Generation failed: " + message)


func _on_generation_timeout():
    print("Generation timed out!")


func cancel_if_running():
    if llama.is_generating():
        llama.cancel_generation()


func _exit_tree():
    cancel_if_running()
    if llama and llama.is_model_loaded():
        llama.unload_model()

Compatible Models

LlamaInterface supports any model in GGUF format. Some recommended models:

Small Models (Steam Deck, mobile devices)

Model Size RAM/VRAM Recommended Use
SmolLM2-360M ~250 MB ~500 MB Very short responses, limited devices
SmolLM2-1.7B ~1 GB ~2 GB Steam Deck, simple NPCs
Qwen2.5-0.5B ~400 MB ~800 MB Basic responses, very fast
Qwen2.5-1.5B ~1 GB ~2 GB Balance for limited devices

Medium Models (Desktop PC)

Model Size VRAM (Q4) Recommended Use
Qwen2.5-3B ~2 GB ~3 GB Simple NPCs, short responses
Mistral-7B ~4 GB ~6 GB Balance between quality/speed
Qwen2.5-7B ~4 GB ~6 GB Complex dialogues
Llama-3.1-8B ~5 GB ~7 GB High overall quality
Tip: Use Q4_K_M or Q5_K_M quantizations for the best balance between quality and performance.

Technical Notes

  • The class automatically initializes the llama.cpp backend when loading a model
  • Only one model can be loaded at a time. Loading a new model unloads the previous one
  • The destructor automatically frees all resources
  • Compatible with multi-threading via OpenMP
  • Supports GPU offloading with CUDA, Vulkan, or Metal (depending on build)
