Wiki / API Reference / DialogueManager

💬 DialogueManager

GDScript Core

Main orchestrator for the dialogue system. Manages conversation execution in multiple modes, integrating dialogue graphs with AI generation.

Note: This class is the main entry point for the dialogue system. It automatically handles AI model loading/unloading, conversation history, and graph execution.

Inheritance

Node → DialogueManager

Description

DialogueManager is the central component that coordinates all aspects of the dialogue system:

  • Graph execution - Navigates through visually defined dialogue nodes
  • AI generation - Integrates with LlamaInterface for dynamic responses
  • Context management - Maintains variables, history, and conversation state
  • Query system - Allows game logic to respond to conditions and actions

Dialogue Modes: The system supports three operation modes:

  • FREE - Open conversation with AI, no graph structure
  • SCRIPTED - Strict execution of the dialogue graph
  • HYBRID - Combines both, allowing transitions between graph and free conversation

Enumerations

DialogueMode

Value Description
FREE Open conversation with AI. The player can write freely and the NPC responds dynamically.
SCRIPTED Execution based exclusively on the dialogue graph. Only predefined options.
HYBRID Allows transitions between free and scripted mode. Special nodes control the transitions.

Method Descriptions

start_dialogue

void start_dialogue(graph: DialogueGraph = null, mode: DialogueMode = HYBRID)

Starts a new dialogue session. If there is an active dialogue, it ends it first.

Parameters

Parameter Type Description
graph DialogueGraph Dialogue graph to execute. If null, starts in FREE mode.
mode DialogueMode Initial execution mode

Behavior

  • Automatically loads the AI model if the graph specifies model_path
  • Applies the graph's AIPreset if defined
  • Initializes local variables from the graph
  • Emits dialogue_started

Example

# Start with predefined graph
var graph = load("res://dialogues/merchant.tres")
dialogue_manager.start_dialogue(graph, DialogueManager.DialogueMode.SCRIPTED)

# Start free conversation without graph
dialogue_manager.start_dialogue(null, DialogueManager.DialogueMode.FREE)

end_dialogue

void end_dialogue(reason: String = "ended")

Ends the current dialogue session and releases resources.

Behavior

  • Stops graph execution
  • Clears local variables
  • Unloads the AI model if it was loaded for this dialogue
  • Emits dialogue_ended with the specified reason

Example

# End by player decision
dialogue_manager.end_dialogue("player_left")

# End by completing the graph (automatic)
# reason will be "graph_completed"

send_player_message

void send_player_message(text: String)

Sends a player message to the dialogue system.

Behavior

  • In FREE mode: Processes the message and generates AI response
  • In SCRIPTED mode with text node: Passes the text to the graph
  • Adds the message to conversation history

Example

# When the player sends a message
func _on_send_button_pressed():
    var text = input_field.text.strip_edges()
    if not text.is_empty():
        dialogue_manager.send_player_message(text)
        input_field.text = ""

select_choice

void select_choice(choice_index: int)

Selects an option by its index when there are options available.

Example

# Create buttons for options
func _on_choices_available(choices: Array[Dictionary]):
    for i in choices.size():
        var button = Button.new()
        button.text = choices[i].text
        button.pressed.connect(func(): dialogue_manager.select_choice(i))
        choices_container.add_child(button)

var gold = dialogue_manager.get_variable("player_gold", 0)

set_variable

void set_variable(name: String, value: Variant, scope: String = "local")

Sets a variable in the dialogue context.

Parameters

Parameter Description
scope "local" = only this dialogue, "global" = persists between dialogues

Example

# Local variable (lost when dialogue ends)
dialogue_manager.set_variable("merchant_mood", "happy", "local")

# Global variable (persists)
dialogue_manager.set_variable("times_talked_to_merchant", 3, "global")

query_condition

bool query_condition(key: String, expected_value: Variant = true, default_value: bool = false)

Queries a condition from game code. Emits condition_query_requested and waits for response.

Example in Game

# In your game script
func _ready():
    dialogue_manager.condition_query_requested.connect(_on_condition_query)

func _on_condition_query(key: String, expected_value: Variant, callback: Callable):
    match key:
        "has_item":
            callback.call(inventory.has_item(expected_value))
        "player_level_above":
            callback.call(player.level >= expected_value)
        _:
            callback.call(false)  # Default for unknown conditions

Complete Example

extends Control
## Example: NPC dialogue interaction

@onready var dialogue_panel: PanelContainer = %DialoguePanel
@onready var speaker_label: Label = %SpeakerLabel
@onready var dialogue_text: RichTextLabel = %DialogueText
@onready var choices_container: VBoxContainer = %ChoicesContainer
@onready var input_field: LineEdit = %InputField

var dialogue_manager: DialogueManager

func _ready():
    # Create and initialize DialogueManager
    dialogue_manager = DialogueManager.new()
    add_child(dialogue_manager)

    # Configure character and world
    dialogue_manager.default_character = load("res://npcs/merchant.tres")
    dialogue_manager.world_context = load("res://worlds/fantasy.tres")

    # Connect signals
    dialogue_manager.dialogue_started.connect(_on_dialogue_started)
    dialogue_manager.dialogue_ended.connect(_on_dialogue_ended)
    dialogue_manager.npc_speaking.connect(_on_npc_speaking)
    dialogue_manager.npc_response_completed.connect(_on_npc_response_completed)
    dialogue_manager.player_choices_available.connect(_on_choices_available)
    dialogue_manager.waiting_for_player_input.connect(_on_waiting_for_input)
    dialogue_manager.error_occurred.connect(_on_error)

    # Connect Query System for game integration
    dialogue_manager.condition_query_requested.connect(_on_condition_query)
    dialogue_manager.action_query_requested.connect(_on_action_query)


func start_conversation():
    var graph = load("res://dialogues/merchant_dialogue.tres")
    dialogue_manager.start_dialogue(graph, DialogueManager.DialogueMode.HYBRID)


func _on_dialogue_started(_graph: DialogueGraph):
    dialogue_panel.visible = true
    print("Dialogue started!")


func _on_dialogue_ended(reason: String):
    dialogue_panel.visible = false
    print("Dialogue ended: ", reason)


func _on_npc_speaking(speaker: String, text: String, is_streaming: bool):
    speaker_label.text = speaker
    if is_streaming:
        dialogue_text.text = ""  # Will be filled with tokens
    else:
        dialogue_text.text = text


func _on_npc_response_completed(full_text: String):
    dialogue_text.text = full_text


func _on_choices_available(choices: Array[Dictionary]):
    # Clear previous options
    for child in choices_container.get_children():
        child.queue_free()

    # Create buttons for each option
    for i in choices.size():
        var button = Button.new()
        button.text = "%d. %s" % [i + 1, choices[i].text]
        var index = choices[i].get("index", i)
        button.pressed.connect(func(): dialogue_manager.select_choice(index))
        choices_container.add_child(button)

    choices_container.visible = true
    input_field.visible = false


func _on_waiting_for_input():
    choices_container.visible = false
    input_field.visible = true
    input_field.grab_focus()


func _on_input_submitted(text: String):
    if not text.strip_edges().is_empty():
        dialogue_manager.send_player_message(text)
        input_field.text = ""


func _on_error(message: String):
    push_error("Dialogue error: " + message)


# ==================== Query System Handlers ====================

func _on_condition_query(key: String, expected: Variant, callback: Callable):
    match key:
        "has_gold":
            callback.call(player_gold >= expected)
        "quest_completed":
            callback.call(completed_quests.has(expected))
        _:
            callback.call(false)


func _on_action_query(key: String, value: Variant, callback: Callable):
    match key:
        "give_item":
            inventory.add_item(value)
            callback.call()
        "take_gold":
            player_gold -= value
            callback.call()
        "start_quest":
            quest_manager.start_quest(value)
            callback.call()
        _:
            callback.call()  # Always call callback

Execution Flow

start_dialogue()
Initialization
  1. Load AI model (if graph.model_path defined)
  2. Apply AIPreset
  3. Initialize variables from graph
  4. Emit dialogue_started
MODE: FREE
waiting_for_player_input
MODE: SCRIPTED / HYBRID
Execute graph
Player Interaction Loop
send_player_message() → npc_speaking → AI generates
select_choice() → navigate graph
Signals: npc_response_completed, player_choices_available
end_dialogue()
  1. Stop GraphRunner
  2. Clear local variables
  3. Unload AI model
  4. Emit dialogue_ended

Technical Notes

  • Auto model management: DialogueManager automatically loads and unloads AI models as specified by the graph. This frees memory when the dialogue ends.
  • Thread safety: AI generation runs in a separate thread to avoid blocking the game.
  • Streaming: When streaming_enabled is true, tokens are progressively emitted via npc_response_token.
  • Query System: Inspired by Questify, it allows game logic to respond to conditions and execute actions from dialogue.
