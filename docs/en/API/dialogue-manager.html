💬 DialogueManager

GDScript Core

Orquestador principal del sistema de diálogos. Gestiona la ejecución de conversaciones en múltiples modos, integrando grafos de diálogo con generación de IA.

Nota: Esta clase es el punto de entrada principal para el sistema de diálogos. Maneja automáticamente la carga/descarga de modelos de IA, historial de conversación, y ejecución de grafos.

Herencia

Node → DialogueManager

Descripción

DialogueManager es el componente central que coordina todos los aspectos del sistema de diálogos:

  • Ejecución de grafos - Navega por nodos de diálogo definidos visualmente
  • Generación de IA - Integra con LlamaInterface para respuestas dinámicas
  • Gestión de contexto - Mantiene variables, historial y estado de conversación
  • Sistema de consultas - Permite que la lógica del juego responda a condiciones y acciones

Modos de Diálogo: El sistema soporta tres modos de operación:

  • FREE - Conversación abierta con IA, sin estructura de grafo
  • SCRIPTED - Ejecución estricta del grafo de diálogo
  • HYBRID - Combina ambos, permitiendo transiciones entre grafo y conversación libre

Enumeraciones

DialogueMode

Valor Descripción
FREE Conversación abierta con IA. El jugador puede escribir libremente y el NPC responde dinámicamente.
SCRIPTED Ejecución basada exclusivamente en el grafo de diálogo. Solo opciones predefinidas.
HYBRID Permite transiciones entre modo libre y scripted. Nodos especiales controlan las transiciones.

Query System (Integración con Juego)

Señal Descripción

Descripciones de Métodos

start_dialogue

void start_dialogue(graph: DialogueGraph = null, mode: DialogueMode = HYBRID)

Inicia una nueva sesión de diálogo. Si hay un diálogo activo, lo termina primero.

Parámetros

Parámetro Tipo Descripción
graph DialogueGraph Grafo de diálogo a ejecutar. Si es null, inicia en modo FREE.
mode DialogueMode Modo de ejecución inicial

Comportamiento

  • Carga automáticamente el modelo de IA si el grafo especifica model_path
  • Aplica el AIPreset del grafo si está definido
  • Inicializa variables locales desde el grafo
  • Emite dialogue_started

Ejemplo

# Iniciar con grafo predefinido
var graph = load("res://dialogues/merchant.tres")
dialogue_manager.start_dialogue(graph, DialogueManager.DialogueMode.SCRIPTED)

# Iniciar conversación libre sin grafo
dialogue_manager.start_dialogue(null, DialogueManager.DialogueMode.FREE)

end_dialogue

void end_dialogue(reason: String = "ended")

Termina la sesión de diálogo actual y libera recursos.

Comportamiento

  • Detiene la ejecución del grafo
  • Limpia variables locales
  • Descarga el modelo de IA si fue cargado para este diálogo
  • Emite dialogue_ended con la razón especificada

Ejemplo

# Terminar por decisión del jugador
dialogue_manager.end_dialogue("player_left")

# Terminar por completar el grafo (automático)
# reason será "graph_completed"

send_player_message

void send_player_message(text: String)

Envía un mensaje del jugador al sistema de diálogos.

Comportamiento

  • En modo FREE: Procesa el mensaje y genera respuesta de IA
  • En modo SCRIPTED con nodo de texto: Pasa el texto al grafo
  • Añade el mensaje al historial de conversación

Ejemplo

# Cuando el jugador envía un mensaje
func _on_send_button_pressed():
    var text = input_field.text.strip_edges()
    if not text.is_empty():
        dialogue_manager.send_player_message(text)
        input_field.text = ""

select_choice

void select_choice(choice_index: int)

Selecciona una opción por su índice cuando hay opciones disponibles.

Ejemplo

# Crear botones para opciones
func _on_choices_available(choices: Array[Dictionary]):
    for i in choices.size():
        var button = Button.new()
        button.text = choices[i].text
        button.pressed.connect(func(): dialogue_manager.select_choice(i))

set_variable

void set_variable(name: String, value: Variant, scope: String = "local")

Establece una variable en el contexto de diálogo.

Parámetros

Parámetro Descripción
scope "local" = solo este diálogo, "global" = persiste entre diálogos

Ejemplo

# Variable local (se pierde al terminar diálogo)

# Variable global (persiste)
dialogue_manager.set_variable("times_talked_to_merchant", 3, "global")

query_condition

bool query_condition(key: String, expected_value: Variant = true, default_value: bool = false)

Consulta una condición al código del juego. Emite condition_query_requested y espera respuesta.

Ejemplo en el Juego

# En tu script de juego
func _ready():
    dialogue_manager.condition_query_requested.connect(_on_condition_query)

func _on_condition_query(key: String, expected_value: Variant, callback: Callable):
    match key:
        "has_item":
            callback.call(inventory.has_item(expected_value))
        "player_level_above":
            callback.call(player.level >= expected_value)
        _:
            callback.call(false)  # Default para condiciones desconocidas

Ejemplo Completo

extends Control
## Example: NPC dialogue interaction

@onready var dialogue_panel: PanelContainer = %DialoguePanel
@onready var speaker_label: Label = %SpeakerLabel
@onready var dialogue_text: RichTextLabel = %DialogueText
@onready var choices_container: VBoxContainer = %ChoicesContainer
@onready var input_field: LineEdit = %InputField

var dialogue_manager: DialogueManager

func _ready():
    # Crear e inicializar DialogueManager
    dialogue_manager = DialogueManager.new()
    add_child(dialogue_manager)

    # Configurar personaje y mundo
    dialogue_manager.default_character = load("res://npcs/merchant.tres")
    dialogue_manager.world_context = load("res://worlds/fantasy.tres")

    # Conectar señales
    dialogue_manager.dialogue_started.connect(_on_dialogue_started)
    dialogue_manager.dialogue_ended.connect(_on_dialogue_ended)
    dialogue_manager.npc_speaking.connect(_on_npc_speaking)
    dialogue_manager.npc_response_completed.connect(_on_npc_response_completed)
    dialogue_manager.player_choices_available.connect(_on_choices_available)
    dialogue_manager.waiting_for_player_input.connect(_on_waiting_for_input)
    dialogue_manager.error_occurred.connect(_on_error)

    # Conectar Query System para integración con juego
    dialogue_manager.condition_query_requested.connect(_on_condition_query)
    dialogue_manager.action_query_requested.connect(_on_action_query)


func start_conversation():
    var graph = load("res://dialogues/merchant_dialogue.tres")
    dialogue_manager.start_dialogue(graph, DialogueManager.DialogueMode.HYBRID)


func _on_dialogue_started(_graph: DialogueGraph):
    dialogue_panel.visible = true
    print("Dialogue started!")


func _on_dialogue_ended(reason: String):
    dialogue_panel.visible = false
    print("Dialogue ended: ", reason)


func _on_npc_speaking(speaker: String, text: String, is_streaming: bool):
    speaker_label.text = speaker
    if is_streaming:
        dialogue_text.text = ""  # Se llenará con tokens
    else:
        dialogue_text.text = text


func _on_npc_response_completed(full_text: String):
    dialogue_text.text = full_text


func _on_choices_available(choices: Array[Dictionary]):
    # Limpiar opciones anteriores
    for child in choices_container.get_children():
        child.queue_free()

    # Crear botones para cada opción
    for i in choices.size():
        var button = Button.new()
        button.text = "%d. %s" % [i + 1, choices[i].text]
        var index = choices[i].get("index", i)
        button.pressed.connect(func(): dialogue_manager.select_choice(index))
        choices_container.add_child(button)

    choices_container.visible = true
    input_field.visible = false


func _on_waiting_for_input():
    choices_container.visible = false
    input_field.visible = true
    input_field.grab_focus()


func _on_input_submitted(text: String):
    if not text.strip_edges().is_empty():
        dialogue_manager.send_player_message(text)
        input_field.text = ""


func _on_error(message: String):
    push_error("Dialogue error: " + message)


# ==================== Query System Handlers ====================

func _on_condition_query(key: String, expected: Variant, callback: Callable):
    match key:
        "has_gold":
            callback.call(player_gold >= expected)
        "quest_completed":
            callback.call(completed_quests.has(expected))
        _:
            callback.call(false)


func _on_action_query(key: String, value: Variant, callback: Callable):
    match key:
        "give_item":
            inventory.add_item(value)
            callback.call()
        "take_gold":
            player_gold -= value
            callback.call()
        "start_quest":
            quest_manager.start_quest(value)
            callback.call()
        _:
            callback.call()  # Siempre llamar callback

Flujo de Ejecución

start_dialogue()
Inicialización
  1. Cargar modelo IA (si graph.model_path definido)
  2. Aplicar AIPreset
  3. Inicializar variables desde grafo
  4. Emitir dialogue_started
MODE: FREE
waiting_for_player_input
MODE: SCRIPTED / HYBRID
Execute graph
Player Interaction Loop
send_player_message() → npc_speaking → AI generates
select_choice() → navigate graph
Signals: npc_response_completed, player_choices_available
end_dialogue()
  1. Detener GraphRunner
  2. Limpiar variables locales
  3. Descargar modelo IA
  4. Emitir dialogue_ended

Notas Técnicas

  • Auto-gestión de modelos: DialogueManager carga y descarga automáticamente los modelos de IA según el grafo especifique. Esto libera memoria cuando el diálogo termina.
  • Thread safety: La generación de IA se ejecuta en un thread separado para no bloquear el juego.
  • Streaming: Cuando streaming_enabled es true, los tokens se emiten progresivamente via npc_response_token.
  • Query System: Inspirado en Questify, permite que la lógica del juego responda a condiciones y ejecute acciones desde el diálogo.
