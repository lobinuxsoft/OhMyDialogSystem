// Tips Generales

Modelos Recomendados: Mistral 7B o Llama 3 8B en formato Q4_K_M ofrecen buen balance entre calidad y velocidad.

Memoria: Los modelos 7B requieren ~6GB de RAM. Los modelos 13B+ pueden requerir 16GB o mas.

GPU: Si tenes una GPU compatible con CUDA, habilita n_gpu_layers para acelerar la inferencia significativamente.
