🦙 LlamaInterface

GDExtension C++

Interfaz de bajo nivel para llama.cpp. Permite cargar modelos GGUF y gestionar su ciclo de vida.

Nota: Esta clase es parte del módulo GDExtension nativo. Requiere que el addon esté correctamente compilado para tu plataforma.

Herencia

RefCounted → LlamaInterface

Descripción

LlamaInterface proporciona una API de bajo nivel para cargar modelos de lenguaje en formato GGUF usando la librería llama.cpp. Esta clase maneja la inicialización del backend, carga de modelos, gestión de memoria y contexto de inferencia.

Es la base sobre la cual se construyen los componentes de más alto nivel como AIService y DialogueManager.

Uso Recomendado: Para la mayoría de casos, usar AIService en lugar de instanciar LlamaInterface directamente:

# Forma recomendada - usar AIService singleton
var ai_service := AIService.get_singleton()
if ai_service and ai_service.is_model_loaded():
    # El modelo ya está disponible globalmente
    pass

# Forma directa (bajo nivel) - instanciar LlamaInterface
var llama := LlamaInterface.new()
llama.load_model("res://models/model.gguf")

AIService gestiona el ciclo de vida del modelo, integra con ModelManager para descarga de modelos, y proporciona señales para cambios de estado.

Descripciones de Métodos

load_model

Error load_model(path: String, params: Dictionary = {})

Carga un modelo GGUF desde la ruta especificada.

Parámetros

Parámetro Tipo Descripción
path String Ruta al archivo .gguf. Soporta res:// y user://
params Dictionary Parámetros opcionales de configuración

Parámetros del Dictionary

Key Tipo Default Descripción
n_ctx int modelo Tamaño de contexto en tokens
n_gpu_layers int 0 Capas a offload a GPU (0 = solo CPU)
n_batch int 512 Tamaño de batch para procesamiento
n_threads int auto Threads para generación
n_threads_batch int auto Threads para procesamiento de batch
use_mmap bool true Usar memory-mapped file
use_mlock bool false Bloquear modelo en RAM
vocab_only bool false Solo cargar vocabulario (sin pesos)

Retorno

Retorna OK si el modelo se cargó correctamente, o un código de error:

  • ERR_FILE_NOT_FOUND - El archivo no existe
  • ERR_CANT_OPEN - No se pudo abrir/parsear el modelo
  • ERR_CANT_CREATE - No se pudo crear el contexto

Ejemplo

var llama = LlamaInterface.new()
var err = llama.load_model("user://models/mistral-7b-q4.gguf", {
    "n_ctx": 4096,
    "n_gpu_layers": 0
})

if err != OK:
    push_error("Failed to load model: " + str(err))
    return

print("Model loaded successfully!")

unload_model

void unload_model()

Descarga el modelo actual y libera todos los recursos asociados (contexto, backend, memoria).

Es seguro llamar este método incluso si no hay modelo cargado.

Ejemplo

llama.unload_model()
print("Model unloaded")

is_model_loaded

bool is_model_loaded() const

Verifica si hay un modelo cargado y listo para usar.

Retorno

true si hay un modelo cargado, false en caso contrario.

Ejemplo

if llama.is_model_loaded():
    print("Ready to generate!")
else:
    print("No model loaded")

get_model_info

Dictionary get_model_info() const

Retorna información detallada sobre el modelo cargado.

Retorno

Un Dictionary con las siguientes keys (vacío si no hay modelo cargado):

Key Tipo Descripción
description String Descripción del modelo
path String Ruta del archivo cargado
size_bytes int Tamaño del modelo en bytes
n_params int Número de parámetros
n_ctx_train int Contexto de entrenamiento
n_embd int Dimensión de embeddings
n_layer int Número de capas
n_head int Número de attention heads
n_ctx int Contexto actual configurado
n_batch int Batch size actual
vocab_size int Tamaño del vocabulario
vocab_type int Tipo de tokenizador (0=SPM, 1=BPE, etc.)
bos_token int ID del token BOS
eos_token int ID del token EOS
has_encoder bool Si el modelo tiene encoder
has_decoder bool Si el modelo tiene decoder
is_recurrent bool Si es recurrente (Mamba, RWKV)
rope_type int Tipo de RoPE

Información de GPU/Backend

Key Tipo Descripción
n_gpu_layers int Número real de capas en GPU (0 = CPU only)
gpu_backend_name String Nombre del backend: "Vulkan0", "CUDA0", "Metal", "CPU"
gpu_backend_desc String Descripción del dispositivo (ej: "AMD Radeon RX 9070 XT")

Ejemplo

var info = llama.get_model_info()
if not info.is_empty():
    print("Model: ", info.description)
    print("Parameters: ", info.n_params / 1_000_000_000.0, "B")
    print("Context: ", info.n_ctx, " tokens")
    print("Layers: ", info.n_layer)

    # GPU info
    var gpu_layers = info.get("n_gpu_layers", 0)
    var backend = info.get("gpu_backend_name", "CPU")
    if gpu_layers > 0:
        print("GPU: ", info.get("gpu_backend_desc", ""))
        print("Layers on GPU: %d/%d" % [gpu_layers, info.n_layer])
    else:
        print("Running on CPU only")

get_model_path

String get_model_path() const

Retorna la ruta del modelo actualmente cargado.

Retorno

La ruta del modelo, o un String vacío si no hay modelo cargado.

get_system_info

String get_system_info() const

Retorna información del sistema: características de CPU y backends disponibles.

Retorno

String con formato "FEATURE = 0/1 | FEATURE = 0/1 | ..." incluyendo:

  • CPU: AVX, AVX2, AVX512, FMA, F16C, NEON
  • GPU: VULKAN, CUDA, METAL

Ejemplo

var sys_info = llama.get_system_info()
print(sys_info)
# Output: "AVX = 1 | AVX2 = 1 | AVX512 = 0 | ... | VULKAN = 1 | CUDA = 0"

# Parse specific features
if "AVX2 = 1" in sys_info:
    print("AVX2 supported!")
if "VULKAN = 1" in sys_info:
    print("Vulkan backend available!")

get_chat_template

String get_chat_template() const

Obtiene el template de chat embebido en los metadatos del modelo (formato Jinja2).

Retorno

El template de chat, o String vacío si el modelo no incluye uno.

Nota: La mayoría de modelos de chat modernos (Llama 3, Qwen, Mistral) incluyen su template. Modelos base no suelen tenerlo.

apply_chat_template

String apply_chat_template(messages: Array, add_generation_prompt: bool = true) const

Formatea mensajes de conversación usando el template del modelo. Usa el parser nativo de llama.cpp (minja).

Parámetros

Parámetro Tipo Descripción
messages Array Array de diccionarios con role y content
add_generation_prompt bool Si true, añade el prefijo para que el modelo responda

Ejemplo

var messages = [
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "Hello!"},
    {"role": "assistant", "content": "Hi! How can I help?"},
    {"role": "user", "content": "Tell me a joke."}
]

var prompt = llama.apply_chat_template(messages, true)
var response = llama.generate(prompt)

count_tokens

int count_tokens(text: String) const

Cuenta tokens usando el tokenizador exacto del modelo cargado.

Retorno

Número de tokens, o -1 si no hay modelo cargado.

Ejemplo

var text = "Hello, world! This is a test."
var token_count = llama.count_tokens(text)
print("Tokens: ", token_count)  # Varies by model, typically ~8-10

# Verificar que el prompt cabe en el contexto
var model_info = llama.get_model_info()
var max_ctx = model_info.get("n_ctx", 4096)
if token_count > max_ctx - 512:  # Reserve space for response
    print("Warning: Prompt may be too long!")

Generación de Texto

generate

String generate(prompt: String)

Genera texto de forma síncrona (bloqueante) a partir de un prompt.

Parámetros

Parámetro Tipo Descripción
prompt String El texto de entrada para continuar

Retorno

El texto generado, o un String vacío si hay error o no hay modelo cargado.

Ejemplo

var llama = LlamaInterface.new()
llama.load_model("res://models/mistral-7b-q4.gguf")

# Configurar parámetros
llama.set_temperature(0.7)
llama.set_max_tokens(100)

# Generar texto
var response = llama.generate("The quick brown fox")
print(response)  # " jumps over the lazy dog..."
Nota: Esta operación es bloqueante. Para generación no bloqueante, usa generate_async() o generate_streaming().

generate_async

void generate_async(prompt: String)

Genera texto de forma asíncrona en un thread de trabajo. No bloquea el hilo principal.

Señales emitidas

  • generation_started - Al comenzar
  • generation_completed(text) - Al terminar exitosamente
  • generation_error(message) - Si hay error
  • generation_cancelled - Si se cancela

Ejemplo

func _ready():
    llama.generation_completed.connect(_on_completed)
    llama.generation_error.connect(_on_error)

func generate_response():
    llama.generate_async("What is the meaning of life?")
    # Returns immediately, result via signal

func _on_completed(text: String):
    print("Response: ", text)

func _on_error(message: String):
    push_error("Failed: " + message)

generate_streaming

void generate_streaming(prompt: String)

Genera texto con streaming: emite cada token a medida que se genera. Ideal para mostrar respuestas progresivamente en la UI.

Señales emitidas

  • generation_started - Al comenzar
  • token_generated(token) - Para cada token generado
  • generation_progress(tokens, max_tokens) - Progreso periódico
  • generation_completed(text) - Al terminar (texto completo)

Ejemplo

@onready var label: RichTextLabel = %ResponseLabel

func _ready():
    llama.generation_started.connect(func(): label.text = "")
    llama.token_generated.connect(func(token): label.text += token)
    llama.generation_completed.connect(_on_done)

func start_chat():
    llama.generate_streaming("Tell me about space exploration")

func _on_done(full_text: String):
    print("Generation finished, %d characters" % full_text.length())

is_generating

bool is_generating() const

Verifica si hay una generación asíncrona o streaming en progreso.

Ejemplo

func _on_send_pressed():
    if llama.is_generating():
        print("Already generating, please wait...")
        return
    llama.generate_streaming(input.text)

get_generation_progress

float get_generation_progress() const

Retorna el progreso de la generación actual como valor entre 0.0 y 1.0.

Retorno

tokens_generated / max_tokens. Retorna 0.0 si no hay generación en curso.

Ejemplo

func _process(_delta):
    if llama.is_generating():
        progress_bar.value = llama.get_generation_progress() * 100.0

cancel_generation

void cancel_generation()

Cancela una generación asíncrona o streaming en progreso. Emite generation_cancelled cuando la generación se detiene.

Ejemplo

func _on_cancel_pressed():
    if llama.is_generating():
        llama.cancel_generation()
        status_label.text = "Cancelled"

Parámetros de Sampling

set_temperature / get_temperature

void set_temperature(temperature: float)
float get_temperature() const

Controla la aleatoriedad de la generación.

  • 0.0 = Greedy (siempre elige el token más probable)
  • 0.7-0.9 = Balance creatividad/coherencia (recomendado)
  • 1.0+ = Más aleatorio/creativo

Default: 0.8

set_top_p / get_top_p

void set_top_p(top_p: float)
float get_top_p() const

Nucleus sampling - considera solo tokens cuya probabilidad acumulada sea ≤ top_p.

Default: 0.95 | Rango: 0.0 - 1.0

set_top_k / get_top_k

void set_top_k(top_k: int)
int get_top_k() const

Considera solo los top-k tokens más probables. 0 = desactivado.

Default: 40

set_max_tokens / get_max_tokens

void set_max_tokens(max_tokens: int)
int get_max_tokens() const

Número máximo de tokens a generar. Mínimo: 1.

Default: 256

set_repeat_penalty / get_repeat_penalty

void set_repeat_penalty(penalty: float)
float get_repeat_penalty() const

Penaliza la repetición de tokens. 1.0 = sin penalización.

Default: 1.1 | Rango: 1.0 - 2.0

set_frequency_penalty / get_frequency_penalty

void set_frequency_penalty(penalty: float)
float get_frequency_penalty() const

Penaliza tokens según su frecuencia en el texto generado. Reduce repetición de palabras comunes.

  • 0.0 = Sin penalización
  • 0.5-1.0 = Penalización moderada
  • 2.0 = Penalización fuerte

Default: 0.0 | Rango: 0.0 - 2.0

set_presence_penalty / get_presence_penalty

void set_presence_penalty(penalty: float)
float get_presence_penalty() const

Penaliza tokens que ya aparecieron (independiente de frecuencia). Fomenta nuevos temas.

  • 0.0 = Sin penalización
  • 0.5-1.0 = Fomenta variedad
  • 2.0 = Evita fuertemente repetir conceptos

Default: 0.0 | Rango: 0.0 - 2.0

set_repeat_last_n / get_repeat_last_n

void set_repeat_last_n(n: int)
int get_repeat_last_n() const

Define cuántos tokens hacia atrás considerar para aplicar repeat_penalty.

  • 0 = Desactivado (sin contexto de repetición)
  • 64 = Últimos 64 tokens (recomendado)
  • -1 = Todo el contexto (puede ser lento)

Default: 64

set_min_p / get_min_p

void set_min_p(min_p: float)
float get_min_p() const

Filtra tokens con probabilidad menor a min_p * prob_max.

Default: 0.05 | Rango: 0.0 - 1.0

set_seed / get_seed

void set_seed(seed: int)
int get_seed() const

Semilla para reproducibilidad. 0xFFFFFFFF = aleatorio.

Default: 0xFFFFFFFF (aleatorio)

Stop Sequences

set_stop_sequences

void set_stop_sequences(sequences: PackedStringArray)

Define secuencias que detienen la generación cuando se encuentran.

Ejemplo

# Detener en fin de turno de diálogo
llama.set_stop_sequences(["User:", "\n\n", "[END]"])

get_stop_sequences

PackedStringArray get_stop_sequences() const

Retorna las secuencias de stop configuradas.

clear_stop_sequences

void clear_stop_sequences()

Elimina todas las secuencias de stop.

Timeout

set_timeout / get_timeout

void set_timeout(timeout_ms: int)
int get_timeout() const

Configura el timeout máximo para la generación en milisegundos.

  • 0 = Sin timeout (espera indefinidamente)
  • >0 = Tiempo máximo en ms

Default: 0 (sin timeout)

Ejemplo

# Limitar generación a 10 segundos
llama.set_timeout(10000)

var response = llama.generate("Tell me a story")

if llama.has_generation_timed_out():
    print("Generation timed out!")
    print("Partial response: ", response)

has_generation_timed_out

bool has_generation_timed_out() const

Verifica si la última generación terminó por timeout.

Retorno

true si la última llamada a generate() terminó por timeout.

Señales

Generación Asíncrona

Señal Descripción
generation_started() Emitida cuando comienza una generación asíncrona o streaming
generation_completed(text: String) Emitida cuando la generación termina exitosamente. text contiene el resultado completo.
generation_error(message: String) Emitida cuando ocurre un error durante la generación
generation_cancelled() Emitida cuando la generación es cancelada mediante cancel_generation()

Streaming

Señal Descripción
token_generated(token: String) Emitida para cada token generado durante streaming. Permite mostrar texto progresivamente.
generation_progress(tokens: int, max_tokens: int) Emitida periódicamente con el progreso de generación. Útil para barras de progreso.

Ejemplo de Streaming

func _ready():
    llama = LlamaInterface.new()
    llama.generation_started.connect(_on_started)
    llama.token_generated.connect(_on_token)
    llama.generation_completed.connect(_on_completed)
    llama.generation_error.connect(_on_error)
    llama.generation_cancelled.connect(_on_cancelled)

func start_streaming():
    llama.generate_streaming("Tell me a story about")

func _on_started():
    label.text = ""
    print("Generation started...")

func _on_token(token: String):
    label.text += token  # Append each token as it arrives

func _on_completed(full_text: String):
    print("Done! Total length: ", full_text.length())

func _on_error(message: String):
    push_error("Generation failed: " + message)

func _on_cancelled():
    print("Generation was cancelled")

Ejemplo Completo

extends Node
## Complete example showing sync and async generation with GPU support

var llama: LlamaInterface
@onready var output_label: RichTextLabel = %OutputLabel
@onready var progress_bar: ProgressBar = %ProgressBar

func _ready():
    llama = LlamaInterface.new()

    # Connect async signals
    llama.generation_started.connect(_on_generation_started)
    llama.token_generated.connect(_on_token_generated)
    llama.generation_completed.connect(_on_generation_completed)
    llama.generation_error.connect(_on_generation_error)
    llama.generation_timeout.connect(_on_generation_timeout)

    # Load model with GPU offloading
    var err = llama.load_model("user://models/qwen2.5-7b-q4_k_m.gguf", {
        "n_ctx": 8192,
        "n_gpu_layers": -1,  # -1 = all layers to GPU
        "n_threads": 8
    })

    if err != OK:
        push_error("Error loading model")
        return

    _print_model_info()
    _configure_generation()


func _print_model_info():
    var info = llama.get_model_info()
    print("=== Model Info ===")
    print("Description: ", info.get("description", "Unknown"))
    print("Parameters: %.1fB" % (info.get("n_params", 0) / 1_000_000_000.0))
    print("Context: %d tokens" % info.get("n_ctx", 0))

    # GPU info
    var gpu_layers = info.get("n_gpu_layers", 0)
    var backend = info.get("gpu_backend_name", "CPU")
    if gpu_layers > 0:
        print("GPU: %s (%s)" % [backend, info.get("gpu_backend_desc", "")])
        print("Layers on GPU: %d/%d" % [gpu_layers, info.get("n_layer", 0)])
    else:
        print("Running on CPU")

    # System capabilities
    var sys_info = llama.get_system_info()
    if "VULKAN = 1" in sys_info:
        print("Vulkan: Available")
    if "AVX2 = 1" in sys_info:
        print("AVX2: Available")


func _configure_generation():
    llama.set_temperature(0.7)
    llama.set_top_p(0.9)
    llama.set_max_tokens(256)
    llama.set_repeat_penalty(1.1)
    llama.set_frequency_penalty(0.5)
    llama.set_timeout(60000)  # 60 second timeout
    llama.set_stop_sequences(["User:", "\n\n", "<|im_end|>"])


func generate_with_chat_template():
    # Use model's built-in chat template
    var messages = [
        {"role": "system", "content": "You are a helpful NPC in a fantasy game."},
        {"role": "user", "content": "What quests do you have for me?"}
    ]

    var prompt = llama.apply_chat_template(messages, true)
    var tokens = llama.count_tokens(prompt)
    print("Prompt tokens: ", tokens)

    # Start streaming generation
    llama.generate_streaming(prompt)


func _on_generation_started():
    output_label.text = ""
    progress_bar.value = 0
    print("Generation started...")


func _on_token_generated(token: String):
    output_label.text += token


func _process(_delta):
    if llama.is_generating():
        progress_bar.value = llama.get_generation_progress() * 100.0


func _on_generation_completed(full_text: String):
    print("Done! Generated %d characters" % full_text.length())
    progress_bar.value = 100


func _on_generation_error(message: String):
    push_error("Generation failed: " + message)


func _on_generation_timeout():
    print("Generation timed out!")


func cancel_if_running():
    if llama.is_generating():
        llama.cancel_generation()


func _exit_tree():
    cancel_if_running()
    if llama and llama.is_model_loaded():
        llama.unload_model()

Modelos Compatibles

LlamaInterface soporta cualquier modelo en formato GGUF. Algunos modelos recomendados:

Modelos Pequeños (Steam Deck, dispositivos móviles)

Modelo Tamaño RAM/VRAM Uso Recomendado
SmolLM2-360M ~250 MB ~500 MB Respuestas muy cortas, dispositivos limitados
SmolLM2-1.7B ~1 GB ~2 GB Steam Deck, NPCs simples
Qwen2.5-0.5B ~400 MB ~800 MB Respuestas básicas, muy rápido
Qwen2.5-1.5B ~1 GB ~2 GB Balance para dispositivos limitados

Modelos Medianos (PC de escritorio)

Modelo Tamaño VRAM (Q4) Uso Recomendado
Qwen2.5-3B ~2 GB ~3 GB NPCs simples, respuestas cortas
Mistral-7B ~4 GB ~6 GB Balance calidad/velocidad
Qwen2.5-7B ~4 GB ~6 GB Diálogos complejos
Llama-3.1-8B ~5 GB ~7 GB Alta calidad general
Tip: Usa cuantizaciones Q4_K_M o Q5_K_M para el mejor balance entre calidad y rendimiento.

Notas Técnicas

  • La clase inicializa automáticamente el backend de llama.cpp al cargar un modelo
  • Solo puede haber un modelo cargado a la vez. Cargar un nuevo modelo descarga el anterior
  • El destructor libera automáticamente todos los recursos
  • Compatible con multi-threading via OpenMP
  • Soporta GPU offloading con CUDA, Vulkan o Metal (según compilación)
