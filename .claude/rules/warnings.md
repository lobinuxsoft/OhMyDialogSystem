# Warnings
Report problems using this format:

```
**WARNING: [Type]**
**Prob:** [Desc]
**Imp:** [Impact]
**Fix:** [Difficulty]
**Alts:** 1. [A], 2. [B]
**Rec:** [Opinion]
```

## Types
- **Architecture:** SOLID, coupling.
- **Performance:** O(n²), leaks.
- **Security:** Validation.
- **Scale/Maint:** Hardcoding, duplicates.

## Rule
**Unsure? ASK.** Propose options. Don't guess.
