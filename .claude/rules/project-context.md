# Project Context

## Structure
- `gdextension/`: C++ (llama.cpp, piper)
- `core/`: Main managers (Runtime)
- `editor/`: Visual Graph (Editor-only)
- `memory/`: NPC persistence
- `tts/`: Piper integration
- `localization/`: TranslationServer
